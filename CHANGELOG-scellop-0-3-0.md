- Upgraded `scellop` from 0.1.1 to 0.3.0. The cell population plot previously pulled in its own copy of MUI 6, since scellop listed `@mui/material` and `@mui/icons-material` as direct dependencies; 0.3.0 moves those and Emotion to peer dependencies, so the plot now renders against the portal's own MUI 9 and theme. Its data schema types also moved into a new `@scellop/data-loading` package, which is re-exported from the same entry point, and the axis config's metadata argument widened to allow `undefined` values, so the explicit parameter annotations on the axis `createHref`/`createSubtitle` callbacks were dropped in favor of the types the component already supplies.
