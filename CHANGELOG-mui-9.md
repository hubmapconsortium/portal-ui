- Upgraded Material UI from v7 to v9 (v8 was skipped upstream), along with `@mui/icons-material`, `@mui/system`, `@mui/lab` (now a v9 beta) and `@mui/x-date-pickers` (v8 to v9). The bulk of the change is mechanical and was produced by MUI's own codemods: system props like `mt`, `flexGrow` and `alignItems` are no longer accepted directly on `Box`, `Stack`, `Typography`, `Link` and `Grid` and have moved into each component's `sx` prop across roughly 200 files, and the deprecated `inputProps`, `InputProps`, `ListboxComponent` and `renderTags` props have been replaced by their `slots`/`slotProps` equivalents. Local components that wrap those MUI primitives had their call sites converted the same way, and a shared `mergeSx` helper in `js/helpers/styled` merges a caller's `sx` into a component's own styles. Two behavioral notes: the transfer list on the LineUp page now uses `Stack` where it previously relied on `Grid` with `direction="column"`, which v9 removed, and `ListItemIcon`'s default minimum width drops from 56px to 36px, which tightens the spacing of icon lists site-wide. The v9 browser baseline also rises to Chrome 117, Firefox 121 and Safari 17.
- Fixed two more v9 consequences found while QAing the upgrade. The organ, collection, publication, biomarker and cell type panel lists kept their column widths in shared config objects that were spread onto each cell (`{...desktopConfig.name}`), so the codemod could not see the style props inside them and `flexBasis` and friends were forwarded to the DOM, where React reported them as unknown attributes; those configs are now passed as `sx`. Collapsible detail page sections render their action buttons inside the accordion summary, and since the summary is a `ButtonBase` that defaults to a native `<button>`, that nested a button inside a button. The summary now renders as a `div`, which makes MUI treat it as non-native and supply `role="button"`, `tabIndex` and Enter/Space handling itself, so it stays keyboard-operable.
- Fixed organ icons disappearing. `URLSvgIcon` draws the icon as a CSS mask in its own `sx`, then spread the caller's remaining props after it; once the v9 conversion moved callers from system props to `sx` (`OrganIcon` and the organs panel item), that spread replaced the mask instead of adding to it. The caller's `sx` is now merged with `mergeSx`.
